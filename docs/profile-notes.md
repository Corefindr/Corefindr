# Profile README Notes

This repository is the special GitHub profile repository for `Corefindr`.

The public profile intentionally avoids:

- private client or employer names
- ServiceNow instance URLs or IDs
- employee, requester, caller, or customer details
- proprietary screenshots, code, table names, or implementation internals
- unverifiable certifications or private contact data

The LinkedIn badge in `README.md` uses a placeholder URL. Replace `https://www.linkedin.com/in/your-linkedin-slug/` with the correct public LinkedIn profile URL when ready.

The contribution snake is generated by `.github/workflows/snake.yml` and published to the `output` branch after the workflow runs.
